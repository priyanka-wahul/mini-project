# Hamburger Menu or sidebar 

A simple and responsive **Hamburger Menu** built using **HTML** and **CSS**. This project demonstrates how to create a modern navigation menu without using JavaScript.
I created this in my early web devlopment learning journey.

##  Live Demo

 https://simple-css-hamburgermenu.netlify.app/

##  Features

- Responsive hamburger menu
- Pure HTML & CSS
- Clean and minimal design
- Easy to customize
- Beginner-friendly project

##  Technologies Used

- HTML5
- CSS3

##  How to Run

 Click the hamburger menu icon to view the navigation menu.

## What I Learned

- Building responsive navigation menus
- Using CSS positioning and transitions
- Styling with Flexbox
- Creating interactive UI elements using only CSS
